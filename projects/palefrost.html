    Description

    Palefrost is a survival-horror game set in a frozen post-apocalypse. I originally developed it solo for several years. This was until summer 2025, when I formed a team alongside some artists and a sound designer. Together we joined the RIT MAGIC Maker program. This was an academic co-op which taught me a great deal about scope and project management.
    We later reapplied to the program under the publishing tier in summer 2026, during which I learned how to market a game.

    Process & Challenges

    During the Maker program, I realized the scope of the project was far too large and needed to be reduced make timelines feasible. This served as a valuable lesson in scope management for games. Programming such long-term project has also reinforced the importance of having strong code foundations.
    This project has also taught me a lot regarding game design, such as onboarding players to gameplay mechanics, guiding through subtle cues level design, and creating immersive scenarios.
